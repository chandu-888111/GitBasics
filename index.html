This is V3 1.TO UNDO git restore . or filename 2.after git add filename, to undo git restore --staged filename then git restore filename 3.after git add and made changes but not committed git restore --worktree filename 4.after git commit, to undo git reset --hard HEAD(uncommitted changes will be lost) or git reset --soft HEAD(keep changes in staging area) or git reset --mixed HEAD(keep changes in working directory) logging types 1.git log -p -no for last number of commits 2.git log --pretty==oneline for one line per commit 3.git log --stat for summary of changes in each commit 4.git log --pretty=format:"%h - %an, %ar : %s" for custom format of log output 5.git log --grep="keyword" for search commits with specific keyword in commit message 6.git log --author="author name" for search commits by specific author 7.git log --since="date" for search commits after specific date 8.git log --until="date" for search commits before specific date 9.git log --no-merges for exclude merge commits from log output for push into github 1.git push -u origin branchname for first time push 2.git push origin branchname for subsequent pushes 3.push remote branch to local git fetch origin branchname:branchname 4.git remote -v for check remote repository
