Git Undo Commands

  1. Use git restore . or git restore <filename> to undo local changes.
  2. After git add <filename>, undo staging with git restore --staged <filename> then restore the file.
  3. After staging and changing a file without committing, use git restore --worktree <filename>.
  4. After commit, undo with:
    • git reset --hard HEAD (loses uncommitted changes)
    • git reset --soft HEAD (keeps changes staged)
    • git reset --mixed HEAD (keeps changes in working tree)

Git Log Options

  1. git log -p -n <number> shows patch diffs for the last commits.
  2. git log --pretty=oneline shows each commit on one line.
  3. git log --stat shows a summary of changes per commit.
  4. git log --pretty=format:"%h - %an, %ar : %s" shows a custom commit format.
  5. git log --grep="keyword" searches commits by message keyword.
  6. git log --author="author name" filters commits by author.
  7. git log --since="date" shows commits after a date.
  8. git log --until="date" shows commits before a date.
  9. git log --no-merges excludes merge commits.

Push to GitHub

  1. git push -u origin branchname for the first push.
  2. git push origin branchname for later pushes.
  3. Fetch a remote branch locally with git fetch origin branchname:branchname.
  4. Check remotes with git remote -v.

Pull from GitHub

  1. git pull origin branchname pulls remote changes into local repository.

Clone a Repository

  1. git clone repositoryurl clones a remote repository locally.

Branching and Switching

  1. git branch branchname creates a new branch.
  2. git checkout branchname switches to that branch.
  3. Merge conflicts can be resolved by editing the conflicting files and then adding them with git add.

Forking and Pull Requests

    • When another user forks your repository, you can collaborate by creating pull requests.And there are several options like comment,sync changes,etc.
  1. git remote add upstream repositoryurl adds the original repository as a remote.
  2. git fetch upstream fetches changes from the original repository.
  3. git checkout -b branchname upstream/branchname creates a new branch based on the upstream branch.
  4. git push origin branchname pushes the local branch to the forked repository.
  5. Create a pull request on GitHub to propose changes to the original repository.
